# The fixed onboarding task set (design D6). The procedure in README.md turns
# each task into the files a newcomer must read.
#
# anchor: the declarations the task changes or cannot be done without reading.
#         "Name" searches every package, "pkg.Name" one package clause,
#         "Type#Method" a method, "file:dir/name.ext" a non-Go file by path suffix.
#         An anchor names a symbol, never a path, so it follows a moved file.
# test:   the contract tests to read before the change, by function name.
#
# The set and its anchors were fixed at step 0 and do not change between
# checkpoints. A pure move changes neither a symbol's name nor this file.
